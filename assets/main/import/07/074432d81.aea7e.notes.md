# 074432d81.aea7e.json UI Hide Notes

This file documents manual UI hides made in `074432d81.aea7e.json`.

Do not insert new fields into the compressed Cocos JSON arrays. For example, do not add `_active: false` or extra booleans into node arrays. That changes the serialized schema and can trigger runtime errors such as `m[n[0]] is not a function`.

The current hide method is:

- Set the node content size from `[5,width,height]` to `[5,0,0]`.
- Set the node transform scale values near the end of `_trs` to `0,0,0`.
- For text-only labels, clear the label string when needed.

## Dynamic bottom score and gcoin mode

The bottom score is resolved by `window.__GGEMU_DDZ__.getBottomScore()` in `assets/main/index.19159.js`.

- The default bottom score is 100.
- When the URL contains `gcoin=1`, the bottom score is 10.
- The display, `playerInfo` default, and all settlement rows use the same resolved value.

In gcoin mode, `defines.modifyGold` delegates balance changes to the bridge in `index.html`. The bridge reads `bag_count`, caps losses at the available balance, uses `useBagCoins` for losses, and uses `addBagCoins` for wins. SDK failures are ignored so they cannot block the game.

## Insufficient gold auto top-up

This change is in `assets/main/index.19159.js`, not in the Cocos scene JSON.

The ready/start button used to block game start when `defines.gold <= 0` and showed an ad prompt. Ads are unavailable in this build, so local coin mode grants 500 coins, shows a non-ad message, and continues the original game-start flow. Gcoin mode skips the grant and continues directly.

Search key:

```text
onBtnReadey:function(e,t)
defines.gold<=0
```

Current behavior:

```text
defines.gold<=0 && defines.modifyGold(500)
金币不足，已补充500金币
```

Current code marker:

```text

```

Restore behavior:

```text

```
